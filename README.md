# Horsepower-BMW-Sales-Performance-Analysis
# Project Overview
Business Intelligence Analysis of BMW sales performance using analytics and machine learning
# Objectives
Analyze BMW sales performance over time
Identify best-selling models, regions, and dealers
Understand revenue, quantity sold, and trends
Compare performance by country / year / model / fuel type
# Tools and Technologies
Python(Pandas,Numpy)
Power BI
# Dataset
Source: Kaggle
contains a complete record of BMW car sales from the year 2010-2024.
